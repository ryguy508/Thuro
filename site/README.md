# Baldarelli And Sons website

Static site: `index.html` + `images/`. No build step.

## Putting it on a custom domain
1. Buy/choose the domain (e.g. baldarelliandsons.com) at a registrar (Namecheap, Google Domains/Squarespace, GoDaddy).
2. Host the `site/` folder on any static host (Netlify, Cloudflare Pages, GitHub Pages — all have free tiers).
3. In the host's dashboard, add the custom domain, then copy the DNS records it shows into the registrar's DNS settings.
4. Wait up to a few hours for DNS; HTTPS is automatic.
